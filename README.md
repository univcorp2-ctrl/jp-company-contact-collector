# jp-company-contact-collector

日本企業を売上規模で絞り込み、公式サイト上の公開された法人向け問い合わせ窓口を整理するリサーチ支援ツールです。現在は **LayerXの「バクラク」「Ai Workforce」「AgenticSec」を紹介する営業候補ダッシュボード**を同梱しています。

## Webダッシュボード

`web/` は依存関係のない静的Webアプリです。

```bash
cd web
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

機能:

- 会社名・課題の検索
- 最低年商、業種、都道府県、推奨プロダクト、優先度での絞り込み
- 売上規模・想定部門・提案理由・公式問い合わせ窓口・売上根拠の表示
- 企業別の提案文下書き
- 表示中データのUTF-8 BOM付きCSVダウンロード
- メール送信・フォーム送信は非対応

## データについて

`web/data/contacts.json` には、企業公式サイト・公式IR資料をもとに手作業で確認した大手企業16社のサンプルを収録しています。売上高は比較しやすいよう円換算・概算表示を含みます。営業利用前に、最新資料、企業名、問い合わせ窓口の用途・規約を再確認してください。

確認日: 2026-07-29

## LayerXプロダクトの分類

- **バクラク**: 経費精算、請求書受取、申請、債権管理、勤怠、給与などのバックオフィス自動化
- **Ai Workforce**: エンタープライズ向けの全社横断AI・文書データ活用
- **AgenticSec**: AIネイティブな継続的セキュリティ検証

商品仕様・導入対象は変更されるため、提案時はLayerX公式サイトの最新情報を確認してください。

## 重要な利用条件

このリポジトリは連絡先調査と提案準備のためのものです。

- 個人メールアドレスを収集しません
- メールアドレスを推測しません
- 問い合わせフォームを自動送信しません
- 一斉メールを送信しません
- robots.txt、サイト利用規約、問い合わせ窓口の目的を確認してください
- 日本の広告・宣伝メールは一般にオプトイン規制の対象になり得ます
- 公開された個人識別可能なメールアドレスも個人情報に該当し得ます

法的判断を提供するものではありません。実際のアプローチ前に社内の法務・コンプライアンス確認を行ってください。
